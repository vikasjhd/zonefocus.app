Questions →
Que bloque Zone ?

Zone peut restreindre les apps et sites web sélectionnés pendant une session. Les frameworks Temps d’écran d’Apple appliquent les restrictions sur l’appareil.

Zone peut-il voir mes sélections ?

Non. Apple fournit des sélections opaques : Zone peut les appliquer sans connaître les apps ou sites précis que vous avez choisis.

Puis-je arrêter une session plus tôt ?

Une session normale peut être arrêtée. Le Mode strict rend ce choix plus difficile ; utilisez-le uniquement si vous acceptez la durée choisie.

Faut-il créer un compte ?

Non. Vous pouvez utiliser Zone sans compte.
